# Semana16_ID3_Java - SENATI

Proyecto de VS Code del módulo *Artificial Intelligence with Machine Learning in Java*.

1. Abre esta carpeta en Visual Studio Code (Archivo > Abrir carpeta...).
2. Instala la extensión **Extension Pack for Java** y usa JDK 17 o superior.
3. Abre cualquier archivo de `src` y pulsa **Run** encima del método `main`.

Los programas leen archivos de la carpeta `datos`, por eso deben ejecutarse
con esta carpeta abierta como raíz del proyecto.
